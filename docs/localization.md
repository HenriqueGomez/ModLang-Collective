# Localization

English remains the source and fallback language. The UI follows Minecraft's selected language. Bundled UI translations and the languages available for creating translation projects are separate.

## Target-language policy

New projects offer contemporary languages, including regional and writing-system variants and planned languages in active use, from Minecraft 26.2. Historical, fictional, and joke options are excluded. The picker intersects the supported list with Minecraft's available languages. Existing projects and original source references remain readable; this policy never deletes saved translations.

## Translation status

These are assisted translation drafts, not native-speaker-certified translations. Automated checks verify complete keys, string values, placeholder compatibility, and brand preservation. They do not prove linguistic accuracy, font coverage, text direction, or layout in the running game.

The interface currently bundles 78 locales (including English and regional variants), each with 102 strings, out of 132 allowed target locales. 54 UI locales remain untranslated. Missing locales fall back to English. Do not count fallback English as a completed translation.

Regional English uses the same neutral English wording. Regional Spanish, French, Dutch, Catalan and Chinese variants currently share wording within their language. Austrian German uses standard German, and the Swiss variant uses Swiss standard spelling rather than a dialect-specific rewrite. Filipino/Tagalog share wording. Serbian Cyrillic uses the same translated text as the Latin version. These shared variants need regional review.

## Contributing

Edit the matching UTF-8 JSON under `src/main/resources/assets/modlangcollective/lang/`. Keep every English source key, format arguments such as `%s`, and brand names. Use the same wording for buttons and their references in Help. Do not translate the physical R/Delete shortcuts. Verify reset, removal, and unsaved-change warnings carefully. Run `./gradlew test` and check the language in Minecraft, including long labels and narrow GUI scales.

Original mod JARs and player-authored translation projects are not edited by UI localization. No online translation API is enabled.

The planned-language policy includes community languages such as [Viossa](https://www.viossa.net/en) and modern [Anglish](https://www.reddit.com/r/anglish/comments/an31tl/welcome/); it does not treat them as historical or fictional solely because they were deliberately created.
